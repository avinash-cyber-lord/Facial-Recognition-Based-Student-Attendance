# Facial Recognition-Based Student Attendance System

A Python desktop application for managing student attendance using face
detection and face recognition. The project uses OpenCV and Tkinter to
capture student face samples, train a recognition model, identify
registered students, and record attendance.

**Repository owner:**
[avinash-cyber-lord](https://github.com/avinash-cyber-lord)\
**Repository:**
[Facial-Recognition-Based-Student-Attendance](https://github.com/avinash-cyber-lord/Facial-Recognition-Based-Student-Attendance)

## Overview

The system uses a webcam to detect and recognize registered student
faces. When a student is recognized, the application can record their
attendance and store attendance information for later review.

This repository is based on the original project by
[KhomZ](https://github.com/KhomZ). Please retain the original project
credits when using or modifying the code.

## Features

-   Login screen with username and password.
-   Student details management.
-   Capture and store student face samples.
-   Train the face recognition model.
-   Take attendance using face detection and recognition.
-   Export attendance reports to CSV.
-   Store attendance records in an SQLite database.
-   Developer and help pages.

## Technologies Used

-   **Python** --- application logic.
-   **OpenCV** --- face detection and recognition.
-   **Tkinter** --- desktop graphical user interface.
-   **SQLite** --- attendance data storage.

## Algorithms

-   **Haar Cascade:** used for face detection.
-   **LBPH (Local Binary Patterns Histograms):** used for face
    recognition.

1.  Clone this repository:

    ``` bash
    git clone https://github.com/avinash-cyber-lord/Facial-Recognition-Based-Student-Attendance.git
    ```

2.  Open the project folder:

    ``` bash
    cd Facial-Recognition-Based-Student-Attendance
    ```
